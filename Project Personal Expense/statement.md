# Personal Expense Tracker
## Problem Statement
It can be difficult to keep track of daily expenses, especially when we make many small payments. This project is a simple Python program that helps users record and manage their expenses.

## Scope
The project allows users to add, view, calculate and delete expenses. It can also show category-wise expenses and the highest expense. The data is saved in a text file so that it can be used again when the program is opened.

## Target Users
This project is mainly useful for students and other individuals who want to keep track of their daily spending.

## High-Level Features
- Add expenses
- View expenses
- Calculate total expenses
- Calculate category-wise total
- Delete expenses
- Find highest expense
- Show categories
- Save and load expenses
- Check user input
