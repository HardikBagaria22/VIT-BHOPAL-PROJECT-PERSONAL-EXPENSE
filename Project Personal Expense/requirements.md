# Project Requirements

## Functional Requirements

1. The user can add a new expense.
2. The user can view all saved expenses.
3. The user can calculate the total expense.
4. The user can calculate the total expense for a category.
5. The user can delete an expense.
6. The user can find the highest expense.
7. The user can view the categories.
8. The program can save and load expenses from a text file.

## Non-Functional Requirements

1. The program should be simple and easy to use.
2. The program should give proper messages for invalid input.
3. The program should save expense data correctly.
4. The program should be easy to understand and maintain.
